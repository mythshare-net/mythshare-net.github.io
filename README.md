# MythShare - Celtic & Welsh Mythology Retro Games

Welcome to **MythShare** – a collection of 8-bit browser games inspired by Celtic and Welsh mythology, including tales from the Mabinogion and other ancient folklore.

## 🎮 Games

- **Wyrm** – A Celtic twist on the classic snake game
- **Cwm Annwn** – Welsh folklore first-person shooter set in the Otherworld
- **Blodeuwedd's Flight** – Atmospheric platformer based on the Fourth Branch of the Mabinogi
- **Cauldron of Rebirth** – Roguelike dungeon crawler inspired by the Pair Dadeni
- **Taliesin's Quest** – Rhythm-based adventure following the legendary bard
- **The Wild Hunt** – Endless runner meets racing game

## 🌐 Live Site

Visit [mythshare.net](https://mythshare.net) to explore our games.

## 📜 About

MythShare brings ancient Celtic and Welsh mythology to life through nostalgic retro-inspired video games. Our games draw from:

- **The Mabinogion** – Medieval Welsh prose stories
- **Celtic Folklore** – Tales of the Tuatha Dé Danann and ancient heroes
- **Welsh Legends** – Stories of Annwn, the Tylwyth Teg, and the great bards

## 🛠️ Technology

This is a static website hosted on GitHub Pages — no build step.

- `index.html` / `styles.css` — the page and its 8-bit Celtic styling
- `js/sprites.js` — 16×16 pixel-art sprites drawn from ASCII maps onto `<canvas data-sprite="…">`
- `js/scene.js` — the animated title-screen night scene (respects `prefers-reduced-motion`)
- `js/app.js` — sprite painting, footer year, and a certain well-known cheat code
- `assets/` — pixel knotwork band and drystone wall textures
- `og-image.png` — social preview card
